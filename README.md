## 📖 About The Project

**SmartHire AI** is an enterprise-grade, AI-powered recruitment and candidate assessment platform that helps candidates **practice technical, HR, and behavioural interviews** through automated AI mock sessions, while also enabling **live coder-recruiter interview rooms** — all from a single unified console.

The platform combines a **React 19 + TypeScript** frontend with a **Python FastAPI** backend, integrates **Google Gemini AI** for resume analysis and interview question generation, and uses **Ultravox Voice AI** to power natural, real-time voice-based mock interviews with full transcript and telemetry logging.

---

## ✨ Key Features

- 🧠 **AI-Generated Interviews** — Automatically generated technical, HR & behavioural interview questions tailored to the candidate's profile
- 📄 **ATS Resume Analyzer** — Upload a resume and get an instant ATS compatibility score, strengths, weaknesses & experience breakdown powered by Gemini AI
- 🎙️ **Voice-Based Mock Interviews** — Real-time conversational AI interviews using Ultravox Voice AI with live transcripts
- 🖥️ **Hardware Readiness Check** — Pre-interview camera/mic diagnostics before entering the interview room
- 🔴 **Live Interview Rooms** — Join live recruiter-hosted interview sessions in real time
- 📊 **Interview Results & Telemetry** — Full conversation transcripts, decision analytics & performance telemetry after every session
- 🕘 **Interview History Dashboard** — Track all past mock and live interviews in one place
- 🔐 **Secure Authentication** — JWT-based login/register flow with protected candidate dashboard

## ⚙️ Getting Started

### Prerequisites
- Node.js (v18+)
- Python 3.11+
- npm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/jaswanthpatibandla-35/SmartHire-AI.git
cd SmartHire-AI

# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
pip install -r requirements.txt
```

### Environment Variables

Create a `.env` file in the backend directory with:

```env
GEMINI_API_KEY=your_gemini_api_key
ULTRAVOX_API_KEY=your_ultravox_api_key
JWT_SECRET=your_jwt_secret
DATABASE_URL=your_database_url
```

### Run the app

```bash
# Start backend
cd backend
uvicorn main:app --reload

# Start frontend (in a new terminal)
cd frontend
npm run dev
```
