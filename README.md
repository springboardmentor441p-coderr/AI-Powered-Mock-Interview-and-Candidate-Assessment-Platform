# 🚀 SmartHire AI

# Intelligent AI-Powered Recruitment, Mock Interview, and Candidate Assessment Platform

SmartHire AI is an end-to-end AI-powered recruitment platform that transforms the hiring process through intelligent resume screening, adaptive AI interviews, voice-based conversations, live coding assessments, recruiter management, and detailed candidate analytics.

The platform provides candidates with a realistic interview experience while enabling recruiters to efficiently evaluate and manage applicants using Artificial Intelligence.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/SmartHire-AI.git
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Backend

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

---

# 🔑 Environment Variables

Create a `.env` file.

```env
GEMINI_API_KEY=your_gemini_api_key
ULTRAVOX_API_KEY=your_ultravox_api_key
JWT_SECRET_KEY=your_secret_key
DATABASE_URL=your_database_url
```

# 📌 Conclusion

SmartHire AI demonstrates how Artificial Intelligence can modernize recruitment by automating candidate evaluation and enhancing hiring efficiency.

The platform combines ATS resume analysis, adaptive AI interviews, voice-based conversations, live coding assessments, recruiter workflow management, and AI-generated performance reports into a unified hiring ecosystem.

Candidates receive an interactive interview experience with real-time feedback, while recruiters benefit from intelligent candidate screening, centralized interview management, and data-driven hiring decisions.

With integrations such as **Google Gemini AI** for intelligent reasoning and **Ultravox Voice AI** for natural voice conversations, SmartHire AI showcases the practical application of Generative AI in Human Resource Technology.

The project follows modern full-stack development practices using React, FastAPI, REST APIs, SQL databases, responsive UI design, and scalable deployment, making it a strong foundation for future enterprise recruitment systems.
